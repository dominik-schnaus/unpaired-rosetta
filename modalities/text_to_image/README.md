# Text-to-image generation through the alignment

A caption is embedded (MPNet or Contriever), mapped into the image embedding space by an aligner, and generated by
an RAE diffusion model that is conditioned on image embeddings and never sees text (Sec. 4.5, App. B and C.2). The
experiments are `experiments/text_to_image.py` (Fig. 6d, Figs. 15-18) and `experiments/text_to_image_scores.py`
(Tables 6 and 7), and this package holds the model code they call.

| File | Content | Environment |
| --- | --- | --- |
| `__init__.py` | Names, captions, sampling settings and paths | any |
| `setup.sh` | Submodules `external/RAE` and `external/Scale-RAE`, our RAE patch, the pretrained RAE decoder | none |
| `rae/DiTDH-S_DINOv2-B_raemean.yaml` | The diffusion model: DiT-DH-S on RAE DINOv2-B latents, conditioned on the mean-pooled latent | none |
| `train_rae.sbatch` | Its training on ImageNet-1K (400 epochs, 4 A40, fp32) | `text2image` |
| `sample.py` | Caption embeddings, the language-to-image maps, and sampling (grids and benchmark prompts) | `text2image` |
| `scale_rae.py` | Scale-RAE, the paired reference model of Tables 6 and 7 | `scale-rae` |
| `prompts.py` | The prompts of CyclePrefDB-T2I and MS COCO val2014 and their real images | `default` |
| `scores.py`, `tifa.py` | CLIPScore, VQAScore, TIFA and CycleReward | `t2i-metrics` |

## Setup

```bash
modalities/text_to_image/setup.sh            # submodules, patch, RAE decoder (1.6 GB)
pixi install -e text2image -e t2i-metrics -e scale-rae
```

The trained diffusion transformer (`ditdh-s_dinov2b_raemean/checkpoints/ep-0000399.pt`, its EMA weights) is
expected at `$UNPAIRED_ROSETTA_ROOT/checkpoints/rae/`. To train it yourself (4 GPUs, about three weeks with
preemptions), run `sbatch modalities/text_to_image/train_rae.sbatch /path/to/imagenet/train` from the repository
root. The paper uses the checkpoint written at step 2,010,000, in the last of the 400 epochs.

## Environments

The three stacks cannot share one solve, so each has its own pixi environment (see `pyproject.toml`):

* `text2image`: RAE's own pins (torch 2.8 cu129, timm 0.9.16, transformers 4.56.2), the versions that trained the
  paper's diffusion model and sampled its images.
* `t2i-metrics`: t2v-metrics (VQAScore) requires image-reward, which pins timm 0.6.13 against RAE's 0.9.16. It uses torch 2.6
  and transformers 4.49, as for the paper's scores.
* `scale-rae`: Scale-RAE's inference pins (torch 2.2, transformers 4.37).

The experiment scripts run in the default environment and start every stage in its environment as a subprocess.

## Reproducibility

* Sampling is deterministic on a given GPU. The grid images of the paper are reproduced bit for bit from the paper's
  maps on an RTX 4500 Ada. The benchmark images use TF32 matmuls, so on another GPU model they differ in the last
  bits (measured: median PSNR 54-56 dB against the paper's images).
* Scale-RAE generates its image tokens autoregressively, so small numerical differences change the whole image: on
  an RTX 4500 Ada its images for the paper's seeds differ from the paper's (similar content).
* The scores depend on the GPU in the last digits (TF32 convolutions, bfloat16 VQAScore): rescoring the paper's
  images (64 prompts of each table, all 18 rows) changes a score by at most 5e-3 (CLIPScore), 2e-2 (VQAScore) and
  3e-2 (CycleReward), and TIFA is identical.
